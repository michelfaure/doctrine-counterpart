## 1. Promotion ou amendement de règles existantes (N ≥ 3 au journal)

1. **Am.R19 — cadence « une passe par défaut » entre dans la norme Live.** Elle a été décidée le
   20/08 « hors cycle de version » et n'existe que dans la règle privée. Mesures depuis : les passes
   supplémentaires ont surtout réparé les précédentes ou tourné sur un bloc déjà saturé. Corollaire à
   promouvoir avec elle : **quand les régressions se concentrent sur un bloc, l'énumération exhaustive
   du bloc remplace la passe suivante** (31/08, 08-09/09 — où l'énumération a trouvé 2 défauts
   qu'aucune des 3 passes n'avait vus —, 10-11/09, 14/09). N ≥ 4.

2. **R19 clause privilèges sort de `[provisional]`, et s'amende.** N ≥ 4 (19/08, 31/08, 01/09 ×2,
   22/09). Amendement mesuré le 22/09 : après `REVOKE ALL … FROM PUBLIC`, `anon` garde EXECUTE —
   les default privileges l'accordent **nominativement** à la création. Les deux REVOKE sont dus
   (PUBLIC **et** anon/authenticated), et seule la sonde `has_function_privilege` fait foi.

3. **Am.R19 déclencheur — les diffs d'affichage mordent, mais sur l'instrument.** N = 4 (18/08,
   18/09, 22/09, 23/09) : diffs hors déclencheur strict (lecture pure, copy, badge), review lancée
   quand même, morsure à chaque fois — trois fois sur le filet de test plutôt que sur le code livré,
   une fois sur le périmètre d'un agrégat de travail. Question à trancher : élargir le déclencheur à
   « affichage de données d'argent ou de contrat », ou consigner que la review y a une autre valeur
   (vérifier l'instrument) sans l'imposer.

4. **Am.R4 — élargir un gate, c'est ouvrir tous les chemins qu'il fermait.** La phase-0 d'Am.R4
   énumère les lecteurs/écrivains d'un état ; elle doit aussi s'appliquer quand on **élargit un
   prédicat, une whitelist ou une garde**, et quand on retire une garde périmée (mesurer ce qu'elle
   masquait avant de la retirer). N = 4 (09/09, 10-11/09, 11/09, 14/09 — ce dernier : un correctif
   qui fait aboutir un appel externe rend atteignable tout le code d'après-succès).

5. **Am.R4 — comparer les prédicats des lecteurs, pas seulement les recenser, et le faire sur l'état
   APRÈS les autres correctifs de la même passe.** N = 3 (10/09 composition de deux correctifs
   justes en faille ; 11/09 deux lecteurs d'une même constante scopant sur deux mailles ; 21/09).

6. **Am.R17 — un filet doit rougir sur la neutralisation et le déplacement, pas seulement sur la
   suppression.** N ≥ 4 (03/09, 18/09, 22/09 ×2). Chaîne présente ≠ condition qui la déclenche ;
   compteur global ne distingue pas 1+1+1 de 3+0+0 ; `toContain` se satisfait d'un texte qui a
   changé de bloc. Corollaire : la mutation de falsification est **vérifiée appliquée** (contrôle
   discriminant, ancré sur le bloc muté) avant lecture du verdict (10/09, 21/09, 22/09), et une
   mutation verte est tranchée « trou » ou « mutant équivalent », jamais laissée ambiguë (10/09, 22/09).

7. **Am.R17 — un oracle dérivé du SUT ne mesure rien.** N ≥ 4 (18/08, 31/08, 10-11/09, 22/09) : liste
   recopiée, constante partagée par l'oracle et le code, test qui n'importe rien du sujet et finit
   cité comme preuve. Et toute assertion sur un fichier source écarte les commentaires, JSX compris
   (10/09, 18/09).

8. **Am.R17(3) — l'état terminal d'un livrable visible, c'est « rendu à l'écran ».** N ≥ 4 (18/08,
   02-03/09, 08/09, 21/09) : valeur calculée et jamais rendue, composant sans appelant, consigne
   recommandant un geste qui n'existe pas. `tsc` et la suite ne voient rien de cette classe.

9. **Am.R10 — une LECTURE dont l'erreur n'est pas lue est un échec silencieux.** R10 couvre
   `await mutation()` sans `{ error }` ; la classe mesurée est la lecture : timeout ⇒ données vides
   ⇒ « rien à faire » ⇒ la garde passe, en vert (02/09, 03/09, 10/09, 21/09). N ≥ 4. Distinguer
   l'inconnu du négatif dans le type de retour.

10. **Am.R1 — une justification écrite dans le code est une claim.** Docstring, commentaire, message
    de commit ou en-tête de module qui affirme une garde, une provenance ou un invariant : il se
    vérifie comme un « tests verts », et il est pire qu'absent quand il est faux, parce que le lecteur
    suivant croit le chemin analysé. N ≥ 5 (18/08, 09/09, 14/09, 22/09 ×2 dont une provenance inventée).

11. **Am.R1 — un agrégat n'est pas une mesure tant que son périmètre et son unité ne sont pas dits.**
    Agrégat sur un statut technique lu comme un agrégat d'argent ; agrégat sans borne temporelle ;
    agrégat de lignes lu comme agrégat de dossiers. N = 4 (21/09, 22/09 ×2, 23/09) — trois fois en
    position d'alerte, là où une fausse affirmation coûte le plus.

12. **Am.R1 — le code de sortie d'un outil n'est pas le verdict.** N ≥ 5 : `gh pr checks --watch`
    exit 0 sur check rouge (19/08) ; `git rebase … | tail` exit 0 sur conflit (23/09) ; `tsc` exit 134
    = OOM, pas des erreurs de type (18/09, 22/09) ; `gh pr merge` en erreur après avoir mergé (11/09) ;
    statut de job porté par sa dernière commande (22/09). Et le **taux de base** avant toute annonce
    de régression (au moins 6 fois dans le journal).

### 7.2 Réécritures (contradictions R18(c))

- **R17 « exactly one targeted red »** : réfuté (4/4) — mutations à 2-3 rouges légitimes, et 7/7
