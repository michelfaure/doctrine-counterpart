## 3. Candidats — PROMOTION PLEINE proposée (N≥3, screen challenger passé)

1. **R19 sort de `[provisional]`** — la condition v0.9 (« un 3e cas matériel ») est dépassée ×5. **+ Am.R19 température métier** : remplacer « orchestration `actions.ts` » par « surface chaude (paiement/TVA/cron-mutateur/RLS/auth), quel que soit le fichier » ; `[review-ok]` seulement après LECTURE du diff, jamais aveugle. N=3 froids-0-finding + 10 chauds documentés.
2. **Am.R4(a) — attribution causale communiquée à un humain** : « X a causé/supprimé Y » est un claim R1 à sonder AVANT d'être prononcé (la mutation réelle du flux vérifiée). N=3 : D-94 (fausse accusation annulation admin), BRAGADIR (« c'est le SEPA ? »), « carte KO » (S22).
3. **Hoist « travail en vol » → Am.R2 (ou R16)** : sur surface partagée, `gh pr list --state open` + `git branch -a` + `git worktree list` AU DÉMARRAGE du diagnostic — comble la lacune §1-4. N=3 : #334/#340, ADR-0194 (arbre basculé + 5 ADR adjacents), merge FF 11/07. Hoist du feedback user-scope existant (précédent : v0.8 hoist de `challenger_avant_proposition`).
4. **Am.R9/R16 — l'arbre partagé** : un worktree dédié protège le travail de l'agent, PAS l'arbre commun. `git branch --show-current` avant tout merge depuis un tree partagé ; router par ref pur (`git branch -f main <sha>`) ; `git status` propre avant `worktree remove`. N=3 : S1 (`remove --force` détruit du non-committé), S11, S20 (merge FF avance la branche d'autrui).
5. **R17 (slot vacant) — Couverture assertionnelle** : un test vert n'atteste que ce qu'il assarte. Trois clauses : (a) chaque **colonne écrite** par le SUT est assartée (le dry-run « vert » qui masquait `source`, #352) ; (b) le fixture couvre chaque **dimension du modèle** traversée (1 PI → N places, #350) ; (c) le parcours est traversé jusqu'à l'**état terminal métier** (« l'objet créé peut être soldé » — fatal ADR-0200) ; + un filet doit prouver qu'il MORD (mutation SUT → 1 rouge ciblé, S8). N=4, le candidat nouvelle-règle le plus fort du cycle. Complète R3 (critère avant code) et R7 (anti-tautologie contrat) sans les recouvrir : ici c'est la surface d'assertion, pas le critère ni le cas négatif.
6. **Am.R1 facette C — référence jamais exécutée** : un pattern/code à 0 exécution (table vide, RPC jamais tournée, chemin 0 ligne prod) n'est PAS une référence validée ; avant de mirror, vérifier qu'il a réellement tourné + énoncer la condition de validité qui diffère. Même forme logique que facettes A/B (existence ≠ état vérifié). N=4 : S5 (émargement→contrat, condition inversée), S7 (`cloturerAvecSignatures` 0 ligne → bytea hérité), S24-F1 (bug hérité par copie), S11/S13.
