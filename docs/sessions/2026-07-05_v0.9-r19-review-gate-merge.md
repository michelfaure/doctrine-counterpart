## Apprentissages méthodo

1. Un hook Claude Code est une commande shell sur un event d'outil ; il ne peut pas invoquer une slash-command. Toute discipline de gating qui repose sur une slash-command (ex. `/code-review`) se scinde en une *règle* (invoquée par l'agent/l'humain) + un *hook-rappel* bon marché — jamais un « auto-run » hook. L'option review-systématique n'existe que côté serveur (CI), et c'est là, pas dans le hook local, que se paie le coût de parcimonie.
2. Une skill « promue source repo » n'est pas « installée » : l'existence de la source dans un repo portable ≠ un mécanisme vivant user-scope. Vérifier « le mécanisme tourne » = inspecter l'install user-scope / la liste des skills disponibles, pas le repo doctrine. Instance opérationnelle d'Am.R1.
3. Passer `/challenger` sur sa *propre recommandation* (pas seulement un fix) peut réfuter deux étais tout en laissant le cœur debout — le protocole confirme autant qu'il démolit ; l'échafaudage d'une thèse peut être faux sans que la conclusion tombe.
